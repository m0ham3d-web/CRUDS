# CRUDS — Product Management System

A simple and interactive product management system built with HTML, CSS, and JavaScript.

## 📌 About The Project

CRUDS is a web-based application that allows users to manage product records through a clean and user-friendly interface.

The project demonstrates the core CRUD operations: Create, Read, Update, and Delete.

## ✨ Features

- ➕ Create new products
- 📋 Display and manage products
- ✏️ Update existing product information
- 🗑️ Delete individual products
- 🔍 Search products
- 🗂️ Organize products by category
- 💰 Automatic total price calculation
- 💾 Save data using Local Storage
- 📱 Responsive user interface

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## 🚀 Getting Started

### Installation

1. Clone the repository:

```bash
git clone https://github.com/m0ham3d-web/CRUDS.git
```

2. Open the project folder.

3. Run `index.html` in your browser.

No additional dependencies are required.
